# Core Java Learning

A structured repository documenting Core Java concepts, modern language features, and object-oriented design patterns from fundamentals to advanced topics.

---

## 🛠 Tech Stack & Environment

- **Language:** Java 25
- **IDE:** IntelliJ IDEA
- **Version Control:** Git & GitHub

---

## 📂 Repository Architecture

The project is organized into domain-specific packages to maintain separation of concerns and clear modularity:

| Package | Key Concepts Covered |
| :--- | :--- |
| `basics/` | Data types, operators, conditionals, and control flow. |
| `arrays/` | Single and multi-dimensional arrays, arrays of objects. |
| `oop/` | Encapsulation, inheritance, polymorphism, abstraction, constructors (`this`/`super`), interfaces, inner & anonymous classes, sealed classes, and records. |
| `collections/` | `List` (`ArrayList`), `Set`, `Map`, and custom sorting via `Comparable` and `Comparator`. |
| `exceptions/` | `try-catch-finally`, checked/unchecked exceptions, `throw`/`throws`, custom exceptions, and try-with-resources. |
| `threads/` | Multithreading fundamentals, `Thread` class, `Runnable` interface, concurrency, and race conditions. |
| `streams/` | Functional interfaces, lambda expressions, and Stream API pipelines (`map`, `filter`, `reduce`, `sorted`). |
| `annotations/` | Built-in Java annotations and custom metadata definitions. |
